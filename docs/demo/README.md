# Demonstration material

Every image and recording here is the installed Daylight Commons 3.0.0 Chrome package, running on
synthetic pages where every account, post and company is invented and every handle starts with
`demo_`. The one exception is the "run it on us" lookup: a synthetic post links Daylight Commons'
own repository and site, and GitHub and the Internet Archive answered for real.
`scripts/demo/README.md` says how these were made and what the capture changes.

| File | What it shows |
|---|---|
| `demo-install-to-verify.webm`, `.gif` | Under two minutes: the install page, first run, a synthetic thread, a reply's window and its evidence, a lookup's receipts, the saved chain passing the offline check, then a copy with one number changed failing it |
| `finding-place.png` | A reply that speaks as a local of France from an account the platform labels Nigeria |
| `finding-account.png` | A new account with renames |
| `finding-posting.png` | A post sent from an automation app |
| `finding-coordination.png` | The same text from three accounts in one thread |
| `finding-language.png` | Dehumanising language, with the sign's measured precision and interval |
| `finding-theory.png` | A post that names a theory, with what the record shows |
| `finding-fact-check.png` | A claim a fact-checker already reviewed, with their rating |
| `finding-sources.png` | A linked outlet's owner and its cited state link |
| `finding-thread-report.png` | The thread panel: where accounts are based and coordination across the thread |
| `finding-launch-campaign.png` | The launch campaign lens on a synthetic paid launch: documented fact, then inference, each sign with what it does not prove |
| `finding-evidence.png` | Run it on us: receipts from GitHub and the Internet Archive about Daylight Commons' own repository and site |
| `finding-verify.png` | The saved evidence chain checked on the Analyse a file page |
| `page-*-light.png`, `page-*-dark.png` | The extension's own pages (first run, options, popup, Analyse a file, privacy) on both grounds |
| `how-it-works-light.svg`, `-dark.svg`, `.png` | The diagram on the How it works page |
| `demo-evidence-chain.json` | The chain saved in the recording; `radar verify` passes it |
| `demo-evidence-chain-edited.json` | The same chain with one number changed; `radar verify` fails it |
| `verify-*.txt` | The output of `radar verify` on both chains |
| `requests.json` | Every request the browser made during the recording, and what happened to it |
