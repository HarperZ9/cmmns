Daylight Commons options

Choose where Daylight Commons runs, what its window shows and how long it keeps what it has read. Changes apply at once.

Sites

Mastodon servers

Daylight Commons runs on a Mastodon server only after you open it, click the Daylight Commons button and allow it. Removing a server here takes the access back.

    What the window shows

    Reading

    Site cards

    Rest the pointer on a link in a post to see who owns the site, what kind of owner it has, when and where it was founded, any state link, and its fact-check record. To see the same card for a news site you are reading, press Site card for this page in Daylight Commons' toolbar menu. Daylight Commons runs on no news site until you press it.

    Search results

    Off by default. Turning an engine on asks the browser for access to its result pages; Daylight Commons then adds a line of labels under each result and sends nothing anywhere.

    Other coverage

    Outlets

    Your own feeds

    Any RSS or Atom address on https. Adding one asks the browser for access to that feed's host only.

      Data packs

      A data pack adds fact-checks, operation indicators or site notes from someone you choose. Daylight Commons never downloads one: you pick the file. Daylight Commons checks its signature, shows which key signed it and what it adds, and uses it only after you trust that key.

          How old the catalogue is

          A signed head names a release and its catalogue, with a version that only goes up and a date it expires. Pick HEAD.json and HEAD.sig from a release or an offline kit. An older head than one checked here is refused. An expired head is kept and marked Expired; every finding still shows.

          What Daylight Commons keeps

          Everything stays in this browser profile. Older entries are deleted on the next start and whenever you change these numbers.

          Accessibility

          Keyboard: move focus to a post to open its window, Alt+R to move into it, arrow keys between its tabs, Esc to close it.

          Your feedback on signs

          Every sign in the window has This was right and This was wrong. Your marks stay in this browser. Daylight Commons keeps the sign, its kind, the thread it was in and your mark. It keeps the post text only when you tick "include the text" before marking.

          SignRightWrong

          Saving writes a JSON file to your computer. Daylight Commons never sends it. If you want to help measure Daylight Commons, you can attach the file to an issue on Daylight Commons' repository. Read it first: it holds the threads you marked, and the text of any post you chose to include.
