Analyse a file

Choose a saved page, a thread's JSON or a data export from your own account. CMMNS reads it on this device, and the file stays here. It works with every platform closed.

Choose a file

  • Saved page: an X or Reddit thread saved with your browser's Save page as. Any other page is read as one text.
  • Thread JSON: X's TweetDetail response, Bluesky's getPostThread, a Mastodon status context, or CMMNS' own thread shape.
  • Your data export: an X archive's tweets.js, a Reddit export's comments.csv or posts.csv, a Mastodon archive's outbox.json, a Bluesky repository .car file.
  • An image or video: its Content Credentials and AI-generation metadata.
