Media on the page

Tick what to keep. CMMNS downloads each file from the host the page loaded it from, on your click, and keeps it in this browser.

    Where it goes

    Collection

    Each file joins the case list with its SHA-256, its address, the page and the time. "Save case list" in the toolbar menu writes case-inbox.jsonl for cmmns case add, which captures and archives each address again.

    Asks the Internet Archive to save this page. The page's server and the Archive will see the request, and the copy is public. Your browser asks for access to web.archive.org the first time.

    Source protection is on: nothing is downloaded again and no copy is asked for. CMMNS keeps only what this page already holds in memory; for anything else, use your browser's own Save as and add the file to the case.

    Open collections

      Protected media (DRM or encrypted streams) is never saved. CMMNS says so and stops.
